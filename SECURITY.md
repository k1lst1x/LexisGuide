# Security policy

Please do not disclose security vulnerabilities in public issues.

Use the repository's **Security** tab to create a private vulnerability report:
https://github.com/k1lst1x/LexisGuide/security/advisories/new

If private reporting is unavailable, contact the repository owner through their
GitHub profile with a concise description, impact, and reproduction steps. Do
not include real user documents or secrets in the report.
